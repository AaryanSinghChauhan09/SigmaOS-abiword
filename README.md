# SigmaOS AbiWord

This repository is currently a minimal `no_std` component identity scaffold. The library exposes a `Component` named `SigmaOS-abiword`.

It does not contain AbiWord, an office suite, or document editing and rendering functionality. Its current manifest and source do not establish compatibility with the upstream AbiWord project.

## Build

```sh
cargo check --lib
```
